### 👋 About Me

I'm a **QA Automation Engineer** with 2+ years of experience in software testing and test automation, specializing in **Playwright, TypeScript, JavaScript, API testing, and end-to-end testing**. I've spent my career validating complex, enterprise-grade workflows for a higher-education platform — spanning CRM, Admissions, Enrollment, Registration, Student Information Systems, Curriculum, Academic Planning, and Finance.

My current focus is combining traditional QA engineering with **Artificial Intelligence** — building AI agents, LLM-powered testing tools, self-healing locators, and AI-assisted test generation using **MCP (Model Context Protocol)**, **Playwright MCP**, and **Claude Code**.

I'm working toward a career path that moves from **QA Automation Engineer → SDET → AI Automation Engineer → Intelligent Quality Engineering**, with the long-term goal of building AI-native testing systems that reduce manual effort and improve software quality at scale.
